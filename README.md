# 1. Project Title & Description
**Project Title:** JomRyde - Driver Management Portal

**Description:**
JomRyde Driver Portal is a dedicated web application prototype designed specially for ride-hailing drivers under the JomRyde platform. This system serves as an interactive dashboard where drivers can manage their daily operations efficiently. It integrates simulation data, real-time responsive navigation, and analytical charts to provide drivers with key performance indicators (KPIs) such as earnings, ride statistics, and history.

---

# 2. Features Included
The JomRyde Driver web application is fully equipped with features that align with the assignment requirements:

* **Authentication System (Login/Logout):** A secure-looking simulation login screen featuring instant error-handling feedback for incorrect credentials. It also includes a functional logout sequence that clears user access.
* **Main Driver Dashboard:** A comprehensive overview page that displays critical real-time performance summaries, including Total Earnings, Completed Trips, and current Driver Rating.
* **Data Visualisation (Charts Component):** Highly interactive graphical charts that visualize data dynamically. It displays the driver's monthly earning statistics and job completion trends to help analyze peak hours/months.
* **Advanced Data View Pages:** Two dedicated modules to structure and display extensive driver datasets cleanly:
    1.  *Earning History:* A detailed, structured layout highlighting complete tracking of fares, dates, and trip categories.
    2.  *Driver Profile:* A customized page containing personal verification metadata, active vehicle status, and administrative account details.
* **Fully Responsive Navigation & Layout:** A modern sidebar and top navbar layout driven by standard utilities that gracefully scale down into a collapsed mobile-friendly hamburger menu for smartphones and tablets.

# 4. Frameworks / Libraries Used
The technical framework utilized to develop this interface includes:
* **HTML5 & CSS3** - For standard web layout skeleton structure and basic markup.
* **Tailwind CSS Framework** - Used comprehensively to build modern, production-ready, utility-first user interfaces and absolute responsiveness.
* **FontAwesome Icons** - For rich vector icons embedded in the navigation links and dashboard action buttons.
* **Chart.js Library** - A JavaScript library utilized to render dynamic canvas-based bar charts and lines for driver earning analytics.
